RAKANDEV — PAKET ASET LOGO
Tanggal: 13 Oktober 2026

ISI PAKET
6 file PNG: logo horizontal lengkap, ikon RD, dan tulisan RakanDev.
Setiap aset tersedia dalam versi transparan dan versi latar putih.

01-PNG-Transparan/
PNG RGBA dengan kanal alpha. Cocok untuk ditempatkan pada website,
presentasi, atau desain lain tanpa kotak latar putih.

02-PNG-Latar-Putih/
PNG dengan latar putih. Cocok untuk dokumen dan penggunaan langsung.

WARNA ACUAN
- Sea Teal: #086288 — R pada ikon dan seluruh tulisan RakanDev.
- Sky Blue: #97D7FF — D pada ikon.
- Harbor Blue: #4D8DBA — warna pendukung palet; tidak digunakan
  pada kombinasi logo utama yang dipilih.

PANDUAN SINGKAT
- Gunakan logo-horizontal.png untuk identitas lengkap di header website.
- Gunakan ikon-rd.png untuk simbol merek secara terpisah.
- Gunakan teks-rakandev.png untuk wordmark signature secara terpisah.
- Pertahankan rasio gambar saat mengubah ukuran; pada web gunakan
  height: auto. Versi warna ini paling jelas pada latar putih atau terang.
- File disertakan pada resolusi ekspor aslinya tanpa pembesaran tambahan.
- PNG adalah gambar raster. Tulisan signature merupakan grafis logo,
  bukan file font TTF/OTF atau aset vektor SVG.
